# How to upload the weekly route

*A 2‑minute job for whoever is setting this week's run.*

The club's route page — **https://gpx.billingerunning.club** — shows the route for the
**upcoming Wednesday run** automatically. It does this by reading a GPX file from our shared
Google Drive folder. Your only job each week is to **put the correctly‑named GPX file in
that folder**. You never touch the website.

**Shared folder:**
👉 https://drive.google.com/drive/folders/167G1f3wpk85hLEdKkiio1x-0TaErFmrF

---

## The quick version

1. Get this week's route as a **`.gpx`** file.
2. Rename it to the **week number**, e.g. **`37.gpx`** — or add the run name: **`37-Electric Dog.gpx`**.
3. Upload it to the **WeeklyRoutes** Google Drive folder (link above).
4. Check it shows on **https://gpx.billingerunning.club**.

That's it. The rest of this page is just detail.

---

## Step by step

### 1. Get the GPX file
Export the run's route as a **GPX** file from wherever you plan it (Strava, Komoot, Garmin
Connect, OS Maps, etc. — look for "Export GPX" or "Export as GPX"). It's the same file we
share on WhatsApp.

### 2. Find the week number
Two easy ways:
- **Easiest:** open **https://gpx.billingerunning.club** — the week number is shown right at
  the top (e.g. *"Week 37"*). Use that number.
- Or count it yourself: it's the ISO week number of the run's **Wednesday**.

### 3. Rename the file
Rename the file so it **starts with the week number**. You can optionally add the run's name
after a dash or space:

| You want… | Name the file… |
|---|---|
| Just the route | `37.gpx` |
| Route with a name shown on the page | `37-Electric Dog.gpx` |

**Naming rules**
- ✅ Start with the number: `37.gpx`, `37-Electric Dog.gpx`, `37 Electric Dog.gpx`
- ✅ A leading zero is fine: `07-Trail Loop.gpx`
- ❌ Don't put words before the number: ~~`Electric Dog 37.gpx`~~, ~~`Week 37.gpx`~~
- ❌ Must end in `.gpx` (not `.gpx.txt`, not a `.zip`)
- One file per week — if you add a second file for the same week, only one will show.

### 4. Upload to Google Drive
- Open the **WeeklyRoutes** folder:
  https://drive.google.com/drive/folders/167G1f3wpk85hLEdKkiio1x-0TaErFmrF
- **Drag the file in**, or click **New → File upload**.
- If a file for that week already exists (from last year), it's fine to **replace it** — when
  Drive asks, choose *"Replace existing file"*. (If you instead get `37 (1).gpx`, delete the
  old one so there's only one week‑37 file.)

### 5. Check it worked
Open **https://gpx.billingerunning.club**. If it's the upcoming week, the route appears
straight away. If you've uploaded a **future** week, click **Next →** until you reach it.

You should see the map, the distance, and (if you named it) the run title.

---

## When to upload

The page always shows the **next Wednesday run**:
- On **Wednesday**, it shows that day's route.
- From **Thursday onwards**, it automatically switches to **next Wednesday's** route.

So aim to have each week's file uploaded **by the Thursday before the run at the latest** —
earlier is better, so anyone planning ahead can see it.

---

## Something not showing?

| Problem | Fix |
|---|---|
| Route doesn't appear | Check the file name **starts with the right week number** and ends in `.gpx`. |
| "No route uploaded yet" | The file isn't in the folder for that week — re‑check the number, or that the upload finished. |
| Two files for one week | Delete the extra so there's only one `NN…​.gpx` per week. |
| Wrong route shows | You may have named it with the wrong week number — rename and re‑upload. |
| Still stuck | Give it a minute and refresh the page. If it persists, contact whoever set the page up. |
